# BotWebSummit
 
### Bot criado para listar todas as empresas e startups participantes do WebSummit 2022 - Portugal

- Usando as bibliotecas Pandas, Pyperclip, Pyautogui e Selenium, foi feito um webscrapping de todas as startups que participaram do WebSummit 2022 - Portugal.
- Essa autoação entrava na página das startups participantes, entrava em cada uma delas e buscava informações como: Nome,	Descrição,	País,	Website e	LinkedIN.
- Essa informações eram inseridas dentro de uma planilha excel, para que o time comercial fizesse as análises pertinentes. 
- As informações foram utilizadas para analisar o ramo e localidade de cada startup para que o time comercial tomasse algumas decisões baseadas nessas informações.
- A automação rodou por 3 horas e buscou 362 startups e suas informações.
